# nosherkhalid.github.io

Personal portfolio of **Nosher Khalid**, Senior iOS Engineer: [nosherkhalid.github.io](https://nosherkhalid.github.io)

Plain HTML, CSS and a little JavaScript, with no build step. Hosted on GitHub Pages.

```
index.html            # the whole site
assets/css/style.css  # theme ("Xcode at midnight")
assets/js/main.js     # scroll reveal, screenshot carousels, active tabs
assets/apps/          # app icons + screenshots
assets/img/           # portrait, favicon
assets/*.pdf          # résumé
```

To update the résumé, replace `assets/Nosher_Khalid_iOS_Resume.pdf` and keep the same filename.
